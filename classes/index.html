How to Manage Classes

Edit a class, add album photos, assign educators, move a class to another grade, and choose what goes in its daily report.

Step by step

  1. Open Classes

    From the side menu, click School Setup, then Classes.

    • Classes are grouped by grade track. Use the page numbers at the bottom to move between grades.
    • Use the search bar, or the Classes and Clubs filters, to find one quickly.

  2. Delete a class

    Click the red bin icon on the class card, then confirm.

    A class that already has registrations, albums, media or daily reports can't be deleted. Educore shows a message instead.

  3. Edit a class

    Click the yellow pencil icon to open the class details on the General tab.

    • Change the class name, grade, financial group and class capacity.
    • Add an online class link and a third-party code.
    • Use the Status switch to turn the class on or off.
    • Set Class Type to Class or Club, and add a short description.

  4. Add album photos

    Open the Albums tab and click Select a file.

    • Pick the photo from your computer and click Open.
    • Enter a title and description, then click Add New. The album is added to the class.

  5. Assign educators

    Open the Educators tab to see the teachers linked to the class.

    • Select the teacher, choose the subjects they teach, then click Add.
    • If no teacher is selected, Educore reminds you that an educator is required.

  6. Move a class to another grade

    On the Classes page, click the pink arrows icon on the class card.

    • In Move to Grade, choose the new grade under Cycle and click Save Changes.

  7. Activate or deactivate a class

    Click the green thumbs-up icon to change the class status. A message confirms the update.

  8. Set up the daily report

    Click the yellow clipboard icon to open Daily Report Settings.

    • Select the items teachers fill in for each child, such as mood, food, water and diapers. Meals can also ask for a comment and a time.
    • Under Daily Report Q&A, add groups and questions to show in the report.
